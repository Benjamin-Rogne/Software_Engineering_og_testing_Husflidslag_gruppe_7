# Software_Engineering_og_testing_Husflidslag
Benjamin, Oliver, Shakur, Mohammed, Aurora

dette er ett prosjekt for Østfold Husflidslag, der vi lager en nettverks applikasjons løsning for deres organisasjon. der skal det kunne opprettes kurs, aktiviteter og annen informasjon.

-HOW TO RUN-
i backend gå til org/example og kjør APITestMain.java

åpne terminalen i Frontend mappen i projektet og kjør:
npm run dev

URL blir oppgitt i terminalen etter "npm run dev" kjøres.
